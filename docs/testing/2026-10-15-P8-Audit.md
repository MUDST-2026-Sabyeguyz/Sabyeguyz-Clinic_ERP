# P8 audit — current implementation and remaining specification

Audit source at `844e83a`, 15 October 2026. Runtime results อยู่ใน P8/P9 acceptance report หลังรันจริง.

## Dashboard / reports

- `clinicv2/report/ReportController.dashboard` อ่าน attended visits (Arrived/InService/Completed), นับ unique patient และ gender; อ่าน payments ตาม paymentDate แล้วแบ่งรายได้ตาม transaction type. `totalRevenue` จึงเป็นยอดเงินรับตาม implementation ปัจจุบัน.
- ช่วง from/to เป็นวัน Bangkok และ to แบบ exclusive วันถัดไป. Receipts ใช้ saleDate. Client ส่ง optional branchCode.
- ยังไม่มี approved new/returning customer definition หรือ salesToday/paymentsToday/dailySales contract. ไม่เพิ่ม metrics/action ใหม่ก่อน Q11.
- `resolveBranchId` resolve filter ได้แต่ไม่ตรวจสิทธิ์ actor ใน method; appointment-only P1 ที่ผ่านแล้วไม่พิสูจน์ report enforcement. ต้องกำหนด Q9/report permission scope ก่อนอ้าง branch authorization ครบ.
- Staff sales มี course sale-share accounting; รักษาพฤติกรรมเดิมและ regression ไม่แก้ commission จาก P8.

## Calendar

- มี `CalendarController` Manager-only, ต่อสาขา, status/config/sync และ `CalendarSyncService` push/pull แล้ว. รองรับ service-account และ OAuth refresh-token credentials ใน code.
- Outbound จัดการ create/update/cancel/no-show; dirty state retry; etag กัน echo. Inbound รับเฉพาะ reschedule/cancel ของ linked events ขณะ Unconfirmed/Confirmed; เวลาไม่ว่างหรือ visit เริ่มแล้วจะย้อน Google ตามระบบ.
- Event summary มี HN/first name/service; description มี therapist full name/branch. ข้อมูลเหล่านี้ต้องให้ผู้รับผิดชอบอนุมัติ privacy/account policy ก่อนเปิดจริง.
- Duration เป็น default เดียว (60 ใน fixture). Dirty/poll windows และ in-memory lastPoll เป็นข้อจำกัดที่ต้อง review; ไม่อ้าง outbox durable delivery หรือ exactly-once จาก code นี้.
- Existing `calendar.cy.js` ตรวจ create/move/cancel/no echo/retry/inbound conflict/arrived restrictions/manager-only/disconnect setting. ใช้ provider จำลอง ไม่พิสูจน์ live Google account หรือ credentials lifecycle.
- ไม่เริ่ม Calendar package ใหม่หรือเปลี่ยน credential model โดยอนุมานจากแผนเก่า.
