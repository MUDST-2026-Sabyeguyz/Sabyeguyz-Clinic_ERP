## ข้อค้นพบที่ยังไม่แก้ (ต้องตัดสินใจก่อน)
1. ใบตัดคอร์ส (`CourseUsagePrintService`) **ไม่มี endpoint ใดเรียกใช้** ไม่มี API ออก/พิมพ์ซ้ำ และ snapshot เก็บเฉพาะ staff ID (ไม่มี HN, ชื่อเจ้าของ, ชื่อนักกายภาพ) R38 ฝั่ง "เอกสารพิมพ์" จึงยังไม่ครบ ต้องกำหนดรูปแบบเอกสาร/endpoint ก่อน (ตอนนี้แก้ได้แค่รายการการใช้สิทธิ์)
2. การใช้สิทธิ์แบบ walk-in (ไม่มี appointmentId) ยังตัดจากผู้ซื้อเสมอ ผู้รับโอนที่ไม่มีนัดจะใช้ผ่าน API นี้ไม่ได้ ถ้าต้องการให้เลือกผู้ใช้ได้ต้องเพิ่มฟิลด์ใน `POST /api/course-usages` (เป็นการเปลี่ยน contract ต้องแจ้ง B และ frontend)
